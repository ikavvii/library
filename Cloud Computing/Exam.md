An in-depth analysis of the end semester examination question papers (November 2024, March 2025, November 2025, and March 2026) alongside the official syllabus for **23MX31 Cloud Computing** reveals the exam pattern and high-probability topics.

### **Exam Structure & Mark Weightage Summary**

- **Total Marks**: 100 Marks | **Time**: 3 Hours
- **Question Layout**: Exactly 4 Questions corresponding directly to Course Outcomes CO1, CO2, CO3, and CO4 (25 Marks per Unit/CO).
    - **Sub-question (a)**: 3 Marks (Short core concept, diagram labeling, or distinction).
    - **Sub-question (b)**: 10 Marks (Typically split into b(i) [5 Marks] + b(ii) [5 Marks]).
    - **Sub-question (c)**: 12 Marks (Major Part C question; scenario-based problem, architecture design, or split 12-mark choice).

    - **Probability**: 90%
    - **Toughness**: Easy
    - **Study Time Needed**: 1.5 Hours

    - **Probability**: 85%

    - **Probability**: 75%

#### 2. Most Probable Part C Questions (12 Marks)

1. **Scenario-Based Delivery & Deployment Selection**: Analyze an enterprise moving its workload to the cloud. Identify the NIST reference architecture actors and evaluate suitable Cloud Delivery (IaaS/PaaS/SaaS) and Deployment (Public/Private/Hybrid) models with justifications.
2. **Distributed Systems Architecture**: Define a distributed system, detail its 4 core design issues, and explain the fundamental building blocks of distributed architectural models.
3. **Taxonomy & Computing Paradigms**: Classify multiprocessor architectures using Flynn's classical taxonomy and compare Grid, Edge, and Cloud computing paradigms with real-world use cases.

#### 3. Most Probable Part B Questions (5 Marks)

1. Categorize multiprocessor systems based on Flynn's taxonomy (SISD, SIMD, MISD, MIMD).
2. Compare Grid Computing and Cloud Computing in terms of architecture, control points, and pricing models.
3. Differentiate between Data Parallelism and Task Parallelism / shared memory models with illustrative diagrams.
4. Contrast Edge Computing and Cloud Computing in terms of latency, resource constraints, and data proximity.

#### 4. High Priority Topics

- Flynn's Taxonomy (100% repeat record).
- Distributed System Design Issues & Building Blocks.
- NIST Cloud Service Delivery Models (IaaS, PaaS, SaaS).

#### 5. Low Priority Topics

- Implementation Levels of Virtualization.

    - **Probability**: 88%

    - **Study Time Needed**: 1.5 Hours
    - **Type**: Problem-solving-heavy
    - **Importance Reason**: High-probability 12-mark option (March 2026 Q3c(ii), Nov 2025 Q3c(i)) focusing on archive scenarios (Glacier / Glacier Deep Archive for medical/hospital records).
- **Google BigTable Data Model**
    - **Probability**: 85%
    - **Toughness**: Medium

    - **Type**: Concept-heavy
    - **Importance Reason**: Regular 3–5 mark schema diagram question (March 2026 Q3a, March 2025 Q3b(i), Nov 2024 Q2c). Concepts: Row key, Column family, Tablet, Timestamps.
- **Eucalyptus Cloud Architecture**
    - **Probability**: 80%
    - **Toughness**: Medium
    - **Study Time Needed**: 2 Hours
    - **Type**: Memory-heavy
    - **Importance Reason**: Featured in 3 out of 4 papers (March 2026 Q3b, Nov 2025 Q3a, Nov 2024 Q3b(i)). Components: CLC, CC, SC, NC, Walrus.

#### 2. Most Probable Part C Questions (12 Marks)

1. **HDFS Write Operation**: Detail HDFS Architecture. Explain NameNode metadata management (FSImage and EditLog) and step-by-step pipeline write operations for a 500MB file with a block size of 128MB and replication factor of 3.
2. **Map-Reduce Implementation**: Explain the phases of Map-Reduce (Map, Combine, Shuffle, Sort, Reduce). Construct a complete Map-Reduce execution model for a practical case study (e.g., identifying top 10 accessed URLs from daily e-commerce web access logs).
3. **AWS S3 Storage Optimization**: Compare AWS S3 storage classes (Standard, Intelligent-Tiering, Standard-IA, Glacier Instant/Flexible/Deep Archive). Recommend and justify the optimal storage strategy for archiving hospital patient records with occasional urgent retrieval needs.

#### 3. Most Probable Part B Questions (5 Marks)

1. Illustrate the architecture of Eucalyptus cloud and state the functions of Cloud Controller (CLC), Cluster Controller (CC), Storage Controller (SC), and Node Controller (NC).
2. Draw and explain the Google BigTable data model, highlighting Row Keys, Column Families, Tablets, and Timestamps.
3. Sketch the Aneka cloud platform architecture and classify the services provided by its Container component.
4. Differentiate AWS EC2 instance types (On-Demand, Reserved, Spot, Dedicated) with suitable use cases.

#### 4. High Priority Topics

- HDFS Write Protocol Pipeline & NameNode Files.
- Map-Reduce Phases & Case Study Logic Construction.
- AWS S3 Storage Class Comparison & Decision Scenarios.

#### 5. Low Priority Topics

- OpenStack modular architecture details (not tested in recent papers).
- IBM Blue Cloud & Twister/Iterative Map-Reduce syntactic details.
